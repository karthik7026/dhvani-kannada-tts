## Form title

Kannada speech quality — 5 minute listening task

## Description

You'll hear 6 short Kannada audio clips generated by a text-to-speech system.
Rate each on two scales. There are no right answers — react to how it sounds.

Please use headphones or earphones if you can, and listen in a quiet place.
Each clip is under 10 seconds. The whole thing takes about 5 minutes.

---

## Screening (2 questions)

**1. How well do you understand spoken Kannada?**
- Native speaker
- Fluent, not native
- Some understanding
- Very little

*(Drop "Very little" responses when analysing. Report how many you dropped.)*

**2. Are you listening on headphones or a speaker?**
- Headphones / earphones
- Phone or laptop speaker

## Clip allocation

6 clips = 2 sentences × 3 conditions. Enough to compare without fatiguing people.

| Clip | Sentence | Condition | Reveal in report as |
|---|---|---|---|
| 1 | S1 | A vanilla | A |
| 2 | S2 | C profile | C |
| 3 | S1 | B flat rate | B |
| 4 | S2 | A vanilla | A |
| 5 | S1 | C profile | C |
| 6 | S2 | B flat rate | B |

Interleaved so the same condition never appears twice in a row.

---

## Analysis

Per condition, report **mean ± standard deviation** for both scales, and N.

With N around 15 you will probably not reach statistical significance between
adjacent conditions. **Say so.** A report that states "the difference between B
and C was 0.4 MOS, not significant at this sample size" reads as competent. One
that claims a win from 15 responses does not.

Run a paired t-test if you want a p-value:

```python
from scipy.stats import ttest_rel
ttest_rel(scores_C, scores_B)
```

Paired, not independent — the same listener rated both.
